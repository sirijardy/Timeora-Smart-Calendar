# Timeora – Smart Calendar & Scheduler

## About

Timeora is an interactive calendar and scheduling web application designed to help users organize events, manage schedules, and plan daily activities.

## Features

- Interactive dashboard
- Month, Week, and Day calendar views
- Event management interface
- Search and reminder features
- Clean and responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
